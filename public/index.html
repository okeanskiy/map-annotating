Features

    Map Annotator

    A 2D, single-level annotation document for laying out large maps. Everything is stored in map.json in your map folder. Agents can read and edit that file directly and your changes and theirs appear here live.

    V A L P Select, Area, Line, Point tools
    Click Add a vertex while drawing
    Double-click / Enter / right-click Finish the shape
    Backspace Remove last vertex while drawing, or delete the selection
    Esc Cancel drawing / deselect
    Drag handles Move vertices; click a small midpoint dot to insert one
    Alt + click vertex Delete that vertex
    Scroll Zoom
    Drag empty space, Space+drag, middle mouse Pan
    F Fit map to view
    Ctrl+Z / Ctrl+Shift+Z Undo / redo

    Coordinates: (0, 0) is the top-left of the map, +x is east, +y is south. A rendered preview.png is written next to map.json while the editor is open.
